# 斗地主服务端接口文档

本目录存放《狂欢斗地主》接入服务端所需的数据接口设计与需求。

| 文件 | 说明 |
| --- | --- |
| `server-api-requirements.md` | 主文档：背景、接口清单、WebSocket 协议、数据模型、非功能要求、实施阶段与待确认问题 |
| `server-api-catalog.json` | 机器可读接口清单：端点、状态、优先级、WS 命令与事件、错误码、核心模型 |

## 快速阅读

- 只想看「要做什么接口」：主文档 §3 映射总表 + §4 详细接口清单。
- 只想看「实时对局怎么设计」：主文档 §5 WebSocket 实时对局协议。
- 只想看「后端现有能力怎么复用 / 改什么」：主文档 §10。
- 想拿结构化清单生成代码 / Mock：`server-api-catalog.json` 的 `endpoints` 数组。
